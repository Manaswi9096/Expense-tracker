# Expense-tracker

## Introduction
A simple Python project to record and manage daily expenses.

## Features
- Add expenses
- Enter expense name, amount and category
- View all expenses
- Calculate total spending
- Store expense data in a CSV file

## Technologies Used
- Python 3
- CSV module
- OS module

## How to Run
Run expense_tracker.py in a Python environment and follow the menu options.

## Conclusion
This project demonstrates Python functions, loops, conditional statements and file handling.
